# Brain Frontend

> UI standalone para explorar, buscar y gestionar las memorias del MCP Brain.  
> React 19 + Vite 7 + TypeScript · puerto 8082

## Funcionalidades

- **Memories**: lista de memorias con filtro por tipo, paginación y eliminación
- **Stats**: cuadrícula con totales de memoria por tipo
- **SearchView**: búsqueda full-text en todas las memorias
- **MemoryModal**: vista, creación y edición de memorias con soporte Markdown

## Stack

- React 19, Vite 7, TypeScript
- Conexión REST directa a MCP Brain
